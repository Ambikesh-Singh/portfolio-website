## 🚀 About the Project

Welcome to my personal portfolio website!

This project is designed as a digital space where I can introduce myself, showcase what I am learning and building, and provide an easy way for recruiters, developers and others to connect with me.

The website started as a simple HTML/CSS project and was progressively enhanced with JavaScript, responsive design, animations, theme switching and interactive elements.

🎯 **The goal:** Keep the design simple, professional and user-friendly while reflecting my growth as a developer.

## 🎨 Design Philosophy

I wanted the website to follow a simple principle:

> **"Clean design. Clear communication. Real work."**

Instead of overcrowding the website with unnecessary elements, the design focuses on:

**Minimalism** → **Readability** → **Professionalism** → **Interaction**

The interface uses cards, subtle animations, responsive layouts and carefully spaced sections to keep the experience smooth across devices.

---

## 📱 Responsive Experience

The portfolio is designed to work across:
